# Claude Code skills

## /sticky

The Sticky style from the Promark redesign: lime crumpled paper, giant condensed type, tape, stickers and real-time 3D objects. Type `/sticky` in Claude Code to apply it.

Install on macOS, Linux, WSL or Git Bash:

```bash
curl -fsSL https://raw.githubusercontent.com/prompolu/promark-marketing-agency-/promark-preview/claude-skills/install-sticky.sh | bash
```

Install on Windows (PowerShell):

```powershell
irm https://raw.githubusercontent.com/prompolu/promark-marketing-agency-/promark-preview/claude-skills/install-sticky.ps1 | iex
```

Run the same command again to update. Cloud sessions install it through the environment setup script.
