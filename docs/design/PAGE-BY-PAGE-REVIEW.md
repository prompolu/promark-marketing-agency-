Reviewed the studio preview at 1440, 1024, 768, 390 and 320px widths. This includes 60 page/viewport checks and 30 project-popup checks. Desktop and mobile screenshots were reviewed for every route and all three project popups.

Project-popup links now occupy a dedicated wrapping row with 28px spacing on desktop, and separate rows on mobile. Both links use the same 16px CSS arrow, aligned vertically. Information columns use explicit equal tracks and collapse earlier on tablets. The close control stays available while scrolling. Popup copy and galleries share consistent 24–28px vertical gaps and a single left edge.

The second S140RP variant was removed from the project data, so it no longer appears in the case study or project popup. The retained S140RP film is displayed once in each gallery. Descriptions now refer to three films and one portrait creation. Original uploaded files are retained.

CSS and JavaScript URLs carry content hashes to load the latest layout and popup code after publication. Build, metadata and form checks run before publication. No production files are changed by the preview publisher.
